# Compare our devtools plugin with OpenRune-Developer-Tools; adopt upstream's where it does the job

OpenRune-Developer-Tools is upstream's sideloaded MCP plugin. Compare it tool by tool with our devtools (mcp/ front, the client's devtools plugin): each of ours upstream's covers moves to upstream's; each kept is named with why (e.g. Android/APK support, a tool upstream lacks), in docs/ARCHITECTURE.md. Done when the desktop runs upstream's plugin where adopted and the devtools MCP data tools still answer on a LOGGED_IN desktop. Upstream blob shas: evidence/h-reference-deployment/upstream-shas.md (re-check before acting). Part of h-reference-deployment (PRD H8).
